# Adidas Sales Analysis Dashboard

## Overview

This project analyzes Adidas sales performance using Power BI.

## Objectives

- Analyze Total Sales
- Profit Analysis
- Regional Performance
- Product Performance
- Monthly Sales Trend

## Tools

- Power BI
- Power Query
- DAX
- Excel

- Total Sales
- Total Profit

## Insights

- West Region generated the highest sales.
- Men's Street Footwear was the top-selling category.
- Sales peaked during holiday seasons.
